# SynapseX 游戏优化器

这是一个本地运行的 Windows 中文桌面软件，支持《九阴真经》专项配置、游戏进程会话、可回滚的系统调整、启动项管理、网络工具箱、Clash 残留代理修复和统一备份记录。

## 当前版本 0.29.1

- 一键优化前移至主导航；统一页头与导航间距，帮助入口移至顶部，不再遮挡操作按钮。
- 三档选择、分类项目清单、执行汇总分区；支持名称/影响搜索和状态筛选，筛选与翻页不改变勾选。宽窗口左右分栏，小窗口自动上下排列。
- 完整说明按需展开，最大档功能影响始终显示；最近执行记录和恢复入口集中展示。优化定义与应用、备份、恢复逻辑沿用 0.29.0。
- 详见 [布局调整与验证](docs/LAYOUT_0291.md)。

### 0.29.0 三档优化

- 一键优化改为基础 / 最佳 / 最大三档，分别定义 4 / 24 / 72 项；根据本机状态排除已应用及不可用项，数量不是固定执行次数。
- 0.28 新增的 35 项隐私与应用权限设置全部纳入最大档；最佳档包含其中的广告、反馈、CEIP、输入学习等项目。服务、计划任务及更新策略也接入批量执行。
- 点击档位仅载入预览，支持取消勾选、搜索与分页。确认窗口可展开完整清单；逐项备份、执行、回读，失败或点击停止后不再执行后续项。
- 支持按本次精确备份编号逆序恢复；发生外部更改或原值不能核实时停止。不是按“最近一次”猜测恢复，也不是自动切档撤销。
- 三档不包括破坏性清理、设备卸载、安全防护关闭及启动计时器；显卡、电源、网络仍为单独配置入口。最大档可影响麦克风/摄像头权限、定位、打印、索引、后台应用和更新行为，并不代表帧率最高。
- 详见 [三档方案与验证](docs/QUICK_PRESETS_029.md)。仅参考 BoosterX 的三档交互方式，不宣称其内部配置数值完全相同。

### 保留的 0.23.1 兼容性修复

- 修复固定 9800X3D 说明：处理器名称来自本机，大小核依据 Windows CPU Sets 能效等级，不按品牌、代数或线程比例直接推断；拓扑不完整时明确降级。
- CPU 电源方案按本机公开参数过滤。混合架构、多缓存域 AMD、移动设备和未知平台保留平台调度及核心停放，不照搬单台机器的完整方案。参数未完整写入时取消并回滚。
- 优先级使用 Windows 最小所需访问权限，绑定 PID 与进程创建标识，写入后回读；拒绝访问、身份变化和回读不一致不报告成功。重复应用保留原始备份；旧版未验证的优先级备份保留但不自动用于恢复。
- 去掉个人游戏目录和显卡目标路径默认值。启动时从可读取的游戏进程发现安装目录；未找到时由用户选择，显卡目标沿用用户选择或本机已验证路径。
- 不再把任意名称以 SynapseX 开头的电源方案视为当前所选方案，允许切换不同候选。
- 兼容性记录见 `tests/runtime-compatibility-0.23.1.md`。目标发行平台仍为 Windows 10/11 x64；不声称所有 CPU、OEM 固件或受保护游戏均已实机验证。

## 直接使用

双击 `release\0.25.0\SynapseX-Game-Optimizer-0.25.0.exe` 即可运行，无需安装 Node.js，也不会打开浏览器。请先正常退出旧版 SynapseX，避免单实例机制唤醒旧版本。需要管理员权限的功能可在完全退出后，通过右键“以管理员身份运行”启动；界面显示执行服务的实际权限。

首次运行时，Windows SmartScreen 可能提示“未知发布者”。这是因为当前测试版本尚未购买代码签名证书，并不代表程序需要联网安装组件。

## 安全边界

- 九阴配置必须先预览，再由用户明确确认后才会应用。
- `fxgame.exe` 运行期间拒绝写入或恢复配置。
- 按键方案功能已移除；已有文件保留在原位置，不在升级时清理。
- 每次应用前均在 `%LOCALAPPDATA%\SynapseX\state` 创建精确备份。
- 同屏人数、视野范围、扩展视野和镜头距离可逐项自定义；只有用户改动的项目会写入，并与其他九阴配置一起备份和恢复。
- 系统状态检测只读；系统调整含当前用户和整机设置。新增服务、任务、更新项目独立确认和备份。
- 启动项管理覆盖当前用户/整机注册表和启动文件夹；整机操作需要管理员权限。恢复前检查同名内容冲突。
- 网络模块只在 Clash/Mihomo 已关闭且检测到失效的本地回环代理时允许修复，并支持按备份恢复。
- TCP、QoS、DNS、Hosts 等系统级网络写入只在管理员权限下开放；TCP 方案保存 netsh 全局命令、接口注册表和任务卸载原值，QoS 只移除 SynapseX 自己创建的策略。
- 网卡高级配置只识别 EEE、绿色以太网、Gigabit Lite 和网卡省电；不会自动关闭 RSS、校验和、LSO/RSC，也不强制固定速率。
- 不再修改游戏进程优先级，也不默认绑核。
- FPS 使用 Intel PresentMon 1.10.0 读取 Windows ETW 呈现事件，不向游戏注入 DLL；监控支持自动识别和按进程名保存的手动绑定，网络延迟优先探测绑定进程的当前 TCP 对端，服务器拒绝 ICMP 时显示不可达。
- 不包含 DLL 注入、游戏内存修改、封包复制、伪 FEC、网卡轮换或外挂功能。

## 开发与打包

```powershell
pnpm run desktop
pnpm run package:win
```

Windows 便携版输出到 `release/0.25.0` 目录。打包使用已安装的 Electron distribution，避免当前环境中的 ZIP 临时目录重命名失败，不修改第三方运行时。Vite 忽略 release 与 design-evidence 目录，避免 Windows 打包锁文件导致开发预览退出。
