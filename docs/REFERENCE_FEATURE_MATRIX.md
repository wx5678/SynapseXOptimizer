# SynapseX 参考功能整合矩阵

本文件记录 BoosterX 与 NetworkOptimizer 中可见功能的取舍。原则不是复制按钮数量，而是保留对 Windows 游戏环境有明确用途、能够解释且能够恢复的能力。

## 已整合

| 来源 | 功能 | SynapseX 实现 | 安全边界 |
| --- | --- | --- | --- |
| BoosterX | 系统检测与建议 | 系统快照、建议项、逐项说明和状态匹配 | 不根据“模板”盲写注册表 |
| BoosterX | 优化备份与恢复 | 系统、启动项、网络代理、九阴配置分类备份 | 写入前保存精确原值 |
| BoosterX | 启动项管理 | 当前用户 Run/RunOnce 审计、停用和恢复 | 系统级与启动文件夹只读 |
| BoosterX | 应用与服务审计 | 已安装应用、自动服务只读清单 | 不代卸载，不批量停服务 |
| BoosterX | 进程与性能诊断 | CPU/GPU/内存/磁盘快照、fxgame 会话与主线程压力测量 | 不伪造“提升百分比”，不强制绑核 |
| 两者延伸 | OSD 实时监控 | PresentMon FPS／1% Low、游戏连接延迟、CPU、GPU、显存、内存和网速悬浮窗 | ETW 无注入；无法确认的数据明确留空 |
| BoosterX | 电源方案 | 展示、切换、精确恢复原 GUID | 不声称高性能方案必然提高帧数 |
| NetworkOptimizer | 代理诊断 | Clash/Mihomo、WinINet 代理、PAC、回环残留检测 | 只修复可确认的失效本地代理 |
| NetworkOptimizer | 网络状态 | 活动网卡、DNS、默认路由、网关/公网延迟和丢包 | 不把 ICMP 当作游戏服务器延迟 |
| NetworkOptimizer | DNS/TCP/QoS/Hosts/MTU | DNS 实测与可逆切换、TCP 三档方案与 10 个独立参数、指定游戏 DSCP 46、Hosts 备份编辑、路径 MTU 探测与应用恢复 | TCP 写入后复检，QoS 只管理 SynapseX 命名策略 |
| NetworkOptimizer | 网卡配置 | 精确识别 EEE、绿色以太网、Gigabit Lite 和电源管理 | 不关闭 RSS、校验和、LSO/RSC，不强制速率 |
| NetworkOptimizer | 实时网速 | 读取活动网卡计数器的短时速率 | 不下载测速文件，不额外消耗流量 |
| 两者 | 游戏专项配置 | 读取九阴当前配置，支持预设叠加、15 项逐项自定义和恢复，包含天气效果 | 不改游戏程序文件；写入前备份 |
| NetworkOptimizer | 加速器兼容检测 | 识别运行中的加速器与虚拟网卡，网卡高级优化优先使用物理网卡 | 原软件兼容开关只影响 WinDivert；本软件不安装该驱动 |

## 0.4.x 实施范围

| 功能 | 决策 | 理由 |
| --- | --- | --- |
| 游戏进程会话 | 整合 | 展示进程年龄、内存、优先级、亲和性；仅允许临时“高于正常”并可恢复 |
| 电源方案 | 整合 | 列出方案、显式切换并保存原 GUID；不声称“高性能”必然提高帧数 |
| DNS 测速与切换 | 整合 | 对多个公共 DNS 直接查询测速，按网卡备份、应用、恢复 |
| TCP 全局状态与方案 | 已整合为可执行 | 提供均衡、游戏低延迟、高吞吐三档，以及 10 个可单独应用参数；应用前保存 netsh 完整命令、接口注册表和任务卸载值 |
| QoS 策略 | 已整合为可执行 | 用户可绑定任意 exe 并创建 DSCP 46 持久策略；移除操作只处理 `SynapseX_Game_` 命名策略 |
| Hosts | 整合 | 展示状态、备份、编辑和恢复；不提供所谓“万能加速 Hosts” |
| MTU | 整合为探测 | 使用禁止分片探测给出路径建议；应用前仍需用户确认并保存网卡原值 |
| 网卡节能项 | 已整合 | 检测厂商属性与电源管理；只有识别到精确属性时才允许可逆修改 |
| 操作日志 | 整合 | 所有写操作写入本地 JSONL，记录时间、动作、结果和备份编号 |
| 性能瓶颈 | 已整合 | 测量 fxgame 最热线程、单核占用、进程等效核心数并同步读取 GPU 状态 |

## 明确不整合

| 参考功能 | 原因 |
| --- | --- |
| WinDivert 封包复制、重放、伪 FEC、回溯与多发 | 改变真实流量，增加带宽、抖动、驱动兼容和游戏安全风险，不能修复游戏主线程瓶颈 |
| TCP 双发本地 SOCKS 代理 | 两条 TCP 隧道不会把同一条游戏连接变成低延迟连接，且会改变代理链 |
| HypoMux 多网卡轮转 | 适合并行下载连接，不适合要求稳定路径的实时游戏流量 |
| HPET、动态 Tick、TSC、MPO/HAGS 万能开关 | 本机前期证据已否决；无稳定、可复现收益 |
| 批量停用服务、任务和设备 | 机器差异大，收益不确定，容易破坏更新、安全、输入和网络功能 |
| DLL 注入、D3D Hook、内存修改 | 修改游戏进程与反作弊边界，产品不实施 |

## 0.12.0 完成状态

两个参考软件中对《九阴真经》和 Windows 游戏环境有直接用途、能够解释并可安全恢复的本地功能，已完成第一轮整合。0.7.0 增加每游戏 GPU 首选项、分页文件／磁盘／TRIM 健康检查、CPU／DPC／中断抢占采样，以及连续丢包／抖动／P95、路由和网卡错误诊断。0.8.0 新增按 CPU 架构分类的专属电源方案。0.9.0 将所有文字口令改为按钮后二次确认，并补全 MTU 闭环。0.10.0 修复便携版提权启动链，九阴专项改为当前配置读取、逐项自定义、预设叠加、备份和恢复一体化界面。0.10.1 将视野范围、扩展视野、同屏对象数量和最大镜头距离纳入高级自定义。0.11.0 对照 BoosterX 的基础设置重新筛选，快速优化页扩展为 9 项可恢复设置、3 档选择方案和 6 类已实现功能入口。0.12.0 将原先只负责勾选或跳转的入口改为可直接执行的 Windows 基础优化、高性能 GPU、CPU 专属电源方案和组合式一键应用；安全软件、防火墙、UAC、Windows Update、MPO、SysMain 和计时器改动继续排除。

## 0.13.0 完成状态

- 网络页由 TCP/QoS 只读审计升级为真实执行：均衡、游戏低延迟、高吞吐三档方案，10 个独立参数，应用后目标值复检。
- TCP 每次应用前保存 netsh 完整全局命令、相关注册表原值和任务卸载状态，支持最近备份恢复。
- QoS 支持用户输入任意游戏路径或 exe 名，创建 TCP/UDP DSCP 46 持久策略，并只移除本软件创建的策略。
- 系统优化从 9 项扩充到 18 项，新增 MMCSS Games、登录启动延迟、Power Throttling、离线地图更新、推荐内容与静默安装、反馈询问、个性化体验、任务栏动画和菜单延迟。
- 首页网络入口、一键推荐方案和后台精简预设同步改为可执行状态，不再把只读清单算作优化功能。

## 0.14.0 完成状态

- 九阴专项新增已验证的 `weather_enable` 天气效果开关，界面隐藏底层文件名、节名、键名和原始布尔值。
- 网络稳定性测试可读取当前 fxgame.exe 的已建立 TCP 连接，并提供网关、阿里 DNS、DNSPod、114 DNS 和 Cloudflare 作为可选目标。
- 加速器适配会识别运行中的常见加速器、代理和虚拟网卡，网卡高级优化默认选择物理网卡；不复制参考软件的 WinDivert 封包驱动。
- 软件设置页改为真实可保存选项，包括写入前确认、默认网络测试目标、连续测试次数和九阴游戏目录。
