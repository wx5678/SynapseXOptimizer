- 服务：`synapsex-license.service`，以独立无登录系统用户运行，已启用开机启动。

- 数据库：`/var/lib/synapsex-license/licenses.sqlite3`。
- 签名私钥：`/etc/synapsex-license/signing.pem`，只保存在服务器，未写入本记录或客户端。
- 备份：`/var/backups/synapsex-license`；每日 03:20 加最多 15 分钟随机延迟，由 systemd timer 执行。
- 当前备份仅在同一台服务器，**不含签名私钥，也未配置异机备份和保留期限**，不能视为完整灾难恢复方案。

接口包括健康检查、公钥读取、激活和续期；许可管理使用服务器本地 CLI，不开放公网管理接口。激活码和刷新凭据在数据库内只保存哈希；许可使用 Ed25519 签名。离线许可最长有效 7 天，撤销后的既有离线许可不会立即消失。
