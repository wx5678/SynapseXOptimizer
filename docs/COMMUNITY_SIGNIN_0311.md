# 0.31.1 区服选择修复

- 官方 garea 列表包含相同 `id`、相同 `isp`、不同名称的记录。下拉框原先以 `id` 作为 value/key，选中任何共享编号的记录都会显示第一条。
- 新版将 `[分区编号, 官方服务器编号, 名称]` 作为显示选项身份，保存到原 settings.json；签到请求仍只提交官方 server_id，不制造服务器编号。
- 默认显示活动接口 `state=1` 的记录，分区按 `GROUPID=isp` 关联；历史记录通过独立复选框查看，保留官方原始归属，不猜测迁移目标。
- 分区切换清空服务器选择，签名前重新验证分区、编号和具体选项仍然匹配。
- 0.31.0 没有保存名称，不能反推用户当时点了哪个同编号选项。升级后请重新选择并保存一次；不清除登录会话。

验证：48 项 Node 回归测试通过；TypeScript/Vite 构建通过；隔离 Electron 页面交互验证江湖九区仅显示月明沧海、江湖八区仅显示剑啸山河、切换清空、保存后重建页面恢复名称，以及历史同编号选项可独立选择。交互验证使用固定公开数据夹具，没有登录真实账号或实际提交签到。
