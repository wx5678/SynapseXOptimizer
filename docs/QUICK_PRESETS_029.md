# 0.29.0 一键优化三档

用户要求把新增项放进一键优化，按 BoosterX 的基础 / 最佳 / 最大方式选档。本版替换原推荐 / 后台精简 / 全部可选，同时移除旧的另一套“一键推荐”按钮，避免同页两套互不关联的批量逻辑。

## 档位

- 基础：4 项，游戏模式、关闭系统后台录制、Game Bar 提示、MMCSS Games 参数。
- 最佳：24 项，10 项基础 Windows 设置、4 个诊断/反馈计划任务、10 项隐私与活动记录参数。
- 最大：72 项，18 项基础 Windows 设置、13 项服务/任务/更新控制、41 项高级隐私参数。后者包含 0.28.0 新增的全部 35 项，另有活动记录三项、剪贴板两项与必需诊断数据级别。

固定清单及值在 `src/lib/quickPresets.ts`。不从“所有可用开关”动态全选；将来增加的调试或安全开关不会自动混入方案。本机缺失或不可用的项目显示原因，不加入实际执行。已经是目标值的项目显示状态，避免重复应用。最大包含权限、定位、打印、搜索索引、SysMain、后台活动和更新行为变化，清单可逐项取消。

三档不包含文件删除、设备移除、卸载、安全保护关闭、MPO、漏洞缓解或启动计时器。显卡、CPU 电源及网络需要另行确认具体设备、游戏或目标；保留直达入口。本版参考分档方式，不声称复制 BoosterX 的内部参数。

## 执行与恢复

- 选档、搜索、翻页不写系统。每页 12 项，筛选不改变已勾选范围。
- 应用前必需确认本次选项，完整清单可展开查看；不受旧的取消确认偏好影响。
- 调用已有本地真实写入 API，每项执行前重新读取，检查预览状态是否发生变化。写后再读，不把返回成功但值未改变算完成。
- 失败停止后续项；已完成项保留，不进行整个批次的隐式回滚。当前单项失败时依赖底层模块尝试恢复其原值。基础注册表写入本轮新增读回、部分失败回滚及结果记录。
- 关闭页面或点击停止不会强制终止当前系统请求，但不再启动后续请求。记录中的 running/pending/restoring 在下次打开时提示结果待核实；不自动重试。
- 记录存于当前客户端 localStorage，设置原值仍由服务存入本机备份目录。开始下一次应用会替换最近批次索引，旧的设置备份不删除。浏览器存储无法写入时停止，不静默执行没有批次记录的后续项目。
- “恢复本次优化”按备份编号逆序执行，不使用 latest；原值指纹核实后标记已恢复。外部冲突、缺失备份或不能验证时停止，已经恢复的项目保留结果。
- 切回基础档并不自动恢复已应用的最大档；需使用恢复入口。
