# 0.39.11 左侧导航修复

## 动画检查与改动

| 原实现 | 本次改动 | 原因 |
| --- | --- | --- |
| `membership.css` 的父层 drop-shadow 叠加子层动态 clip-path | 删除父层滤镜，隔离绘制，预提示 clip-path 合成 | 变化的裁剪轮廓可能反复使阴影表面失效；这是渲染开销风险，未取得用户游戏满载时的性能追踪 |
| `interface-refinement.css` 仅折叠时隐藏滚动条 | 所有菜单状态隐藏滚动条，保留 overflow-y:auto | 展开时不再插入滚动条、挤压导航内容 |
| `App.tsx` 签到在侧栏之外，侧栏单独响应 hover | 签到归入同一外层区域，共享 hover 与键盘焦点展开 | 指针移到签到不再误触发侧栏收起 |
| 650ms 裁剪与文字平移分别运行 | 500ms 裁剪、200ms 文字透明度，无文字位移和导航布局指示器动画 | 减少并行运动；保留用户明确要求的渐进式抽屉感与可中断反向过渡 |

检查结论：原实现需要修改。已消除确定的滚动条布局变化和悬停边界冲突，并降低滤镜渲染风险；不能将静态截图或源代码测试当作实际游戏满载下零掉帧的证明。

动画用于展示抽屉展开状态和空间连续性；CSS transition，clip-path + opacity，沿用 ease-in-out 曲线。500ms 是用户要求慢速抽屉的例外，键盘导航、减少动态效果、用户关闭动效时立即切换。
