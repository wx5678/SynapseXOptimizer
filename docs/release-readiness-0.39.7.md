# 0.39.7 发布前检查

检查日期：2026-09-16。结论：可以作为小范围测试候选包，尚不能认定为全配置、全功能正式上线通过。自动化测试通过不等于所有硬件上的真实写入都已通过。

## 本次完成

- 悬浮窗支持 16 项可选指标：FPS、1% Low、探测延迟、CPU 占用、GPU/显存、实时网速、CPU 温度、GPU 温度、帧时间、系统内存、游戏内存、GPU 功耗、GPU 频率、显存用量、下载速度、上传速度。保留原来的六项默认选择，不强制全部显示。
- 多项指标自动换行，窗口按指标数量调整尺寸；标签与数值分行，长值截断并提供完整提示。通过 940px 横向和 390px 宫格测试；设置面板实际点击验证了 CPU/GPU 温度独立开关。
- CPU 温度读取已运行的 LibreHardwareMonitor/OpenHardwareMonitor WMI 传感器服务，不自动安装底层驱动。缺少提供方时显示“不可用”，不是 0℃。
- NVIDIA 返回 N/A、空值或不支持字段时转换为不可用值，避免整页解析失败。当前 GPU 详细指标仍来自首张 NVIDIA 显卡，不是自动匹配游戏使用的 GPU。
- 增加悬浮窗隐藏、最小化、置顶状态丢失恢复；切屏后不主动抢焦点；分辨率/工作区改变后校正位置。锁屏与休眠暂停恢复，解锁/唤醒后恢复。主动关闭、软件退出不重新弹出。渲染器崩溃恢复有重试次数限制，并记录受限大小的 overlay-events.jsonl 日志。
- 上述窗口逻辑通过模拟窗口生命周期测试；新版真实游戏 Alt+Tab、独占全屏、显示器切换仍需现场验证，不能以浏览器预览代替。

## 当前确认存在的受限项

本机以管理员权限调查，原始结果：`state/release-check-AxHuZa/Test-ReleaseAvailability/availability.json`。

- CPU 温度：没有可用传感器提供方，所以本机仍显示不可用。若目标是安装后无需其他程序就能读取温度，当前实现尚不满足，需要单独设计、审核和测试传感器依赖。
- GPU：本机 NVIDIA 详细数据可读；AMD/Intel 温度、功耗、频率提供方未补齐，多显卡关联也未完成。
- 网卡：30 项中 29 项可编辑；“网络地址”没有驱动提供的可验证值域，保持只读。29 项的真实网卡写入未在本机逐项执行，编辑/回读/恢复流程使用模拟驱动测试。
- 高级系统参数：59 项中 57 项可读；“Windows 保留存储”返回 Access is denied；“Defender 实时保护”返回无效类。不能把这两项当成可用开关，也不绕过系统限制。
- 实验室 Eco：当前系统查询返回 NTSTATUS 0xC0000002，不支持该接口，应明确显示不支持。不能因为其他实验室测试通过就宣称 Eco 可用。
- NVIDIA 驱动配置 4 类字段可读；本次没有真实改写用户驱动配置。
- DPC/ISR：xperf 存在，但未实际采样；鼠标延迟测试也没有完成真实输入测量。
- 独占全屏、系统安全桌面可能不展示普通桌面悬浮窗，本版不保证覆盖显示。
