# 0.39.4 自定义帧率上限

游戏配置 → 九阴帧率上限：可输入 300–1000 整数，快捷档位 360 / 600 / 750 / 1000。按游戏内部三倍关系向下换算到 3 的倍数：1000 实际写入 999。界面、确认框和操作结果均显示实际值。

高于 762 的实际档位归为实验档：单字节保存格式存在溢出、重新登录回落或配置异常风险。用户必须勾选风险确认，主进程再次验证确认字段。保存或退出前应将游戏内滑条调回不超过 300。这不是持久化格式修复，也不能保证未测试档位的游戏内表现。

保持 VIP 应用、免费恢复、退出游戏后操作、严格资源/模块版本校验、不改 DLL、不注入进程。用户当前游戏资源未被此轮开发修改。

动态补丁仅改变目标 XML 中的 Maximum，通过有界压缩搜索保持原块长度和包索引不变。修改后重新解压校验全部 XML，并比较块外字节。原版备份只创建一次。识别已有自定义资源时使用原版备份检查完整差异，不单凭可修改的元数据判断；丢失软件备份时可从文件选择器重新导入经过哈希验证的原版。

验证：148 项 Node 回归通过；300–999 的 234 个实际档位在本地原版备份上完成只读结构校验（Node 与 Electron 44），输入1000生成的文件哈希与先前用户实测成功的999版本一致。不是234档游戏内实测。浏览器隔离流程验证1000→999、风险未确认时禁用、确认后应用、成功显示999。TypeScript/Vite构建及Windows便携版打包完成。
