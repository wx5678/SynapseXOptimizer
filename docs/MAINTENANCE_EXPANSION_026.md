# 0.26.0 清理与桌面软件管理

本轮继续补齐此前明确缺少的两类实际操作。未向开发电脑应用系统优化、卸载应用或清理用户文件。

## 已实现

- 系统调整 → 临时文件清理：仅实际执行账户 LocalAppData/Temp 与 Windows/Temp；只选择超过 7 或 30 天未修改的 .tmp、.temp、.log。排除只读、重解析点及 SynapseX/Codex/微信附件路径，不触碰下载、文档、桌面、游戏或着色器缓存。
- 扫描显示完整路径、日期、大小、执行账户、范围和读取失败；最多 500 个候选、1000 个目录、约 3.5 秒枚举预算，触限明确说明并非全盘扫描。单目录系统调用自身仍可能超过预算。
- 默认不选中，支持搜索、25 项分页、选择本页、清空。后端持有 10 分钟有效的一次性预览，客户端只能提交 token 与 ID，不能提交任意删除路径。最多保留 10 个扫描会话。
- 删除前再次核对允许根目录、各级目录的重解析点、大小、修改时间、日期条件和独占打开；变化、锁定、缺失文件跳过。非递归永久删除，不经过回收站，记录不是备份。
- 删除前落盘请求记录，逐项记录结果。预览提交后即消耗，网络错误不能重放删除；重新扫描并查看记录。非事务性文件清理，不声称能回滚已经删除的文件。
- 应用与启动项 → 桌面软件管理：HKCU/HKLM 普通及 WOW6432Node 安装记录；搜索、20 项分页、可用性过滤、原卸载入口展开查看。
- 启动前重新查询 ID 与卸载信息指纹，不接受客户端 EXE/命令。直接调用有效绝对 EXE；标准 MSI /I 或 /X ProductCode 转成交互式 /x ProductCode /promptrestart。不调用命令行解释器，不采用 QuietUninstallString，不用 Win32_Product，不直接删程序目录。
- 缺失、间接脚本入口、静默参数、NoRemove、自定义 MSI 参数显示原因。整机范围和实际执行账户显示在界面及确认框。
- 日志区分 pending、launched、failed；启动程序不宣称卸载成功。卸载流程在原软件窗口继续，完成或取消后重新扫描安装记录。记录不备份应用或用户数据。

## 验证

- Windows PowerShell 5.1 与 PowerShell 7.6：测试目录中仅一个一次性 fixture 被删除，验证占用、修改、只读、年龄、扩展名、排除名、越界、目录链接、空/未知 ID、过期、重放、预览数量上限、逐项记录。
- 实际只读读取当时开发电脑安装记录 53 项，52 项解析出直接入口；数量不代表其他电脑。卸载启动全部使用模拟进程启动器，测试错误身份、变化指纹、重复点击、启动失败、事前记录和 MSI/EXE 参数解析；未实际卸载应用。
- Node 11 项回归通过，包括既有优先级入口移除、悬浮窗退出清理、游戏路径持久化与新增接口确认契约。
- 既有高级系统 13 项、后台任务/Appx、六类启动注册表模拟测试通过，没有写入实际系统配置。
- 打包 0.26.0 成功，实际启动打包内 PS5.1 服务进行只读接口测试：安装目录、清理预览、网络、运行时、后台列表及缺失确认拒绝；被移除的优先级/按键方案接口仍不可访问。测试服务完成后退出。
- 开发预览中检查清理 28 项分页、默认未勾选、勾选字节总数、删除确认后取消；桌面软件跨页搜索、无入口禁用、卸载确认后取消；浅色页面截图检查通过。预览数据不进入生产包。

## 剩余范围

仍不能声称已经完整搬入 BoosterX。尚缺全面的清理类别（浏览器、回收站、更新文件等）、Win32 卸载结果自动跟踪、完整服务/设备/修复项目，以及此前未集成的 MPO/HAGS/全屏优化/计时器/存储/安全类调整。当前为 Windows x64 包，不代表验证了所有硬件、Windows 版本或每家软件的卸载器。
