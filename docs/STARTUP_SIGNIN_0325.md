# 0.32.5 — Windows 登录自启与自动签到

## 使用

在“社区签到”开启“开机启动软件”和“打开软件自动签到”，为每个参与账号完成官方登录、保存区服、勾选“参与自动签到”。“软件设置”也提供同一个开机启动开关。默认不登记启动项，不替用户启用自动签到。

自启发生在当前 Windows 用户登录后，而不是未登录的开机阶段。后台驻留系统托盘，双击打开工作台，右键菜单可查看本次签到概况、打开工作台或退出。正常手动启动保持原来打开工作台的行为；关闭工作台仍会退出整个软件、停止采集并关闭悬浮窗和托盘。

## 实现

- 当前用户的 Windows 登录启动项由 Electron `setLoginItemSettings` 管理，固定名称 `SynapseX`，参数 `--synapsex-startup`。读取/保存后核验真实 Windows 状态，读取不会写入或自动重启被 Windows 禁用的启动项。
- 便携版登记 `PORTABLE_EXECUTABLE_FILE` 原始启动器，不登记解压到临时目录的 Electron 可执行文件。打包器 NSIS 模板已核实传递路径和启动参数。移动文件或更换版本后，需要在新位置重新开启开关。
- 后台启动分支不创建主窗口、不启动提权 PowerShell 服务、不启动 FPS 采集。没有新增提权任务或修改 UAC。
- 使用已有隔离账号会话与自动签到逻辑；只处理用户勾选账号，保留今日确认记录及自动尝试去重，不保存密码或安全口令。
- 启动时网络未就绪最多等待 90 秒，再交给既有签到服务尝试一次。网络状态检测仅作提示，不保证官方服务可达。失败需打开工作台处理，不会无限提交。
- 退出期间取消网络等待，销毁托盘并等待现有签到/采集服务结束。后台时再次手动打开 exe 会打开工作台，不会误退出已运行实例。

## 验证

- 85 项 Node 回归测试通过，包括启动项启用/关闭、中文和空格路径、便携路径、Windows 禁用、错误回读、输入校验、未开启自动签到、取消网络等待、后台启动与第二实例处理、退出清理。
- TypeScript 检查及 Vite/Electron 构建通过。
- 原生 Electron 隔离用户目录冒烟测试通过：0 个窗口，0 次子进程启动，正常退出；不读取真实账号、不写真实启动项、不向官方提交签到。
- 浏览器预览核验签到页和软件设置中的新开关、文案与银白主题显示。
- 未替用户开启真实启动项，未重启/注销用户电脑；实际 Windows 登录自启与真实账号自动签到需要用户启用后验证。已有登录过期和官方验证要求仍需人工完成。
