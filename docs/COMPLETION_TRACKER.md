## 不能标为完成的差异

0.29.0 已按用户要求将设置接入一键优化三档：基础 4 项、最佳 24 项、最大 72 项，最大包含新增全部 35 项隐私设置；支持预览取消勾选、按项执行与本次精确恢复。详情及发行验证见 QUICK_PRESETS_029.md。此项完成不等于下列 BoosterX 全量差异已经消失。

- BoosterX 隐私列表与清理类别已经读取；“所有修复”页当前返回空列表，PRO 的内部项目尚未核实。
- 未实现 Spectre/Meltdown 等漏洞缓解开关；没有采用忽略 CPU、微码及系统差异的统一覆盖值。
- 未直接写 HAGS、FSO、Win32PrioritySeparation；目前交由 Windows 原生设置操作。
- 回收站、更新文件深度清理使用 Windows 原生工具，不是本软件自己的逐文件清理实现。
- 不能宣称适配所有电脑：发行包为 Windows 10/11 x64；读取与模拟测试不等于所有硬件和系统版本的实机写入验证。

## 当前证据与外部限制

2026-09-09：只读核实 BoosterX 设备页：MSI；Hyper-V 虚拟化基础驱动、复合总线、虚拟驱动器枚举、UMBus、NDIS 虚拟网卡枚举、远程桌面重定向总线；Bluetooth、打印机、WAN Miniports。其功能收益描述未经独立验证。

此前窗口输入返回 GetCursorPos 拒绝访问；本轮已恢复，不能再以此作为停止理由。已只读浏览清理、隐私和调整页，未点击原软件的应用优化。清理页“189”包含大量重复名称的历史设备实例，不能解释为 189 个不同优化开关。

尚未核实的功能不可标成已经搬完；逐项证据、未实现差异与测试范围见 BOOSTERX_PARITY_028.md。
