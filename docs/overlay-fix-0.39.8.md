# 0.39.8 悬浮窗切屏恢复修复

2026-09-16：只读进程核验发现用户仍运行 0.39.6；未强制关闭旧客户端或游戏。

## 修复内容

- 置顶/透明画面恢复检查从 5 秒缩短为 1 秒。非焦点窗口不一定收到切屏 blur 事件，因此保留周期检查。
- 即使可见/置顶标记仍为真，也重新声明置顶、调整 Z 顺序、请求透明窗口重绘，不重启 FPS 采集，不调用 focus/show 抢焦点，不通过先取消置顶再置顶制造闪烁。
- 显示器工作区查询失败与其他恢复步骤隔离，避免热插拔短暂失败导致整个恢复跳过。
- 锁屏与休眠分别记录，避免系统已唤醒但尚未解锁时恢复窗口。
- 避免自身置顶通知造成循环恢复；渲染器重载异常被捕获。
- 手动重新打开已有窗口走同一恢复入口；ready 回调绑定具体窗口实例，关闭/退出后不再显示，旧回调不操作新窗口。

## 验证

- 新增 9 项回归：静默遮挡、显示器查询失败、锁屏/休眠事件交错、待执行恢复遇到主动关闭、置顶反馈循环、渲染器异常、重复打开、旧窗口延迟事件、软件退出。
- 全部 Node 测试 169/169 通过，TypeScript、Vite、Windows x64 便携包构建通过。
- 首次完整测试命令遗漏 SYNAPSEX_TEST_PYTHON 环境变量，账号测试准备失败；补齐隔离 Python 路径后全部通过。
- 这是自动化窗口替身和生命周期验证；没有冒充真实游戏 Alt+Tab 已实测通过。新版需要退出旧客户端后启动，单实例机制不会用新 EXE 替换旧进程。
- 独占全屏/系统安全桌面仍不保证普通桌面窗口覆盖。本次没有注入游戏、安装驱动或修改游戏文件。
