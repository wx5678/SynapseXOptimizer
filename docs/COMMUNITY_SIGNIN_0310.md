# 0.31.0 社区签到登录测试版

入口：侧栏「社区签到」→「打开官方登录」。本版一个会话，不支持多账号批量签到。

1. 在独立的蜗牛官方窗口完成账号登录、验证码或账号要求的二次验证。
2. 关闭该官方窗口（不是主程序），点击「刷新登录状态」。
3. 选择分区与服务器，保存选择，再点「一键签到」。
4. 完全退出软件重开，进入签到页查看会话是否仍有效。

实现：专用 persistent Chromium partition；官方窗口无 preload、无 Node 权限；IPC 仅主窗口可调用。登录 Cookie 加密快照使用 Electron safeStorage / Windows DPAPI，支持会话 Cookie 重启恢复，不延长已有 expiry。不记录密码、验证码、动态口令或完整密保卡。清除登录时删除该专用会话及加密快照。只访问所列官方 HTTPS 主机，旧 HTTP 回调升级到 HTTPS，不关闭证书校验。

API 根据官方活动脚本接入 init、isp/garea 和 sign。JSONP 按数据解析，不 eval。点击才提交一次，并检查当前登录、服务器与显式操作标记；并发点击合并，不自动重试。原始官方结果码和消息显示在界面中。网络异常尤其是提交超时需要手动刷新核对。

验证：隔离 Electron profile，未登录查询、27 个分区、207 个服务器、Windows 加解密、官方 SSO 页面加载通过；测试未登录真实账号，实际签到请求 0 次。单元测试覆盖加密快照生命周期、有效期、域名校验、重复点击、登录失效和清除登录。

待用户验证：真实账号的蜗牛盾/密保卡分支、官方登录跳转后 init 状态、跨重启官方会话有效期、活动微信限制是否在服务端阻止签到。不能把匿名 API 可达等同于签到已成功；未伪装微信客户端，也不处理或绕过验证码。
