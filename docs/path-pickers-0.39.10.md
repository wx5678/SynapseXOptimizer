# 0.39.10 路径选择入口

## 改动

- 为 Windows 高性能 GPU 首选项、网络 QoS 程序路径、实验室显卡配置、实验室启动优先级、游戏库和后台白名单补齐 EXE 浏览按钮。
- Windows 工具的现有 EXE 选择入口复用公共组件；九阴安装目录继续使用目录选择器，调整其按钮布局。
- 选择程序只回填路径，不应用系统设置。取消选择保留原值；拒绝非 EXE 文件，兼容中文和空格路径。
- 更换显卡目标时清除旧目标的查询状态；Windows GPU 首选项检查不再依赖厂商驱动查询成功。
- 浏览按钮防重复点击；普通浏览器预览中按钮禁用并提示使用桌面客户端，仍可手动填写路径。

## 验证

- `pnpm run build`：通过。
- `node --test tests/*.test.cjs`：178 项通过（账号测试使用本地测试 Python 环境）。
- 新增用例覆盖路径回填、取消、无桌面桥接、选择器失败、非 EXE 拒绝，以及原生选择器的模拟调用和入口覆盖。
- 本地页面核对高性能 GPU 卡片：路径框、浏览 EXE、检查状态按钮布局正常。
- `pnpm run package:win`：成功生成 `release/0.39.10-path-pickers/SynapseX-Game-Optimizer-0.39.10.exe`。

本轮没有应用实际系统优化，也没有在真实 Windows 文件对话框中完成手动点选；原生对话框参数和返回值通过模拟测试验证。
