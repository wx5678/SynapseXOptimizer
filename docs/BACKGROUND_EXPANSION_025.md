# 0.25.0 后台管理扩展

延续用户要求补齐 BoosterX 的授权；不是仅解释方案。本轮增加真实操作接口与 UI，不执行开发电脑的优化。

## 已实现

- 全量本机计划任务目录：搜索、状态筛选、30 项分页；单项启用、停用、记录恢复。保留安全/更新/调度基础目录。不删任务或终止实例。写入前导出 XML；恢复比对除 Enabled 外的 XML 和执行内容，拒绝覆盖外部改动。
- 六类注册表启动项：HKCU、HKLM、WOW6432Node 的 Run/RunOnce；批次备份先于删除，失败尝试回滚，恢复前查冲突。界面勾选不是授权信任来源，后端校验范围。
- 当前账户/公共启动文件夹：只处理直接文件，拒绝重解析点，移动到精确备份路径；不递归移动目录，恢复前校验哈希及同名文件冲突。
- 当前执行账户的普通 Appx/MSIX 应用精简：卸载前重新解析完整包身份并确认；系统组件、商店、安装器、部分共享运行库保留。没有管理员替其他账户操作的隐式行为，UI 显示执行账户。
- 应用记录仅含安装信息，不包含应用数据。恢复只在原清单仍存在且哈希、包身份通过验证时尝试重新注册；Windows 已回收文件则报错要求商店重装。不删除预配包，不强制结束应用，不承诺完整回滚卸载。

## 验证范围

Windows PowerShell 5.1 实际只读扫描：235 个任务、85 个应用、0 个直接启动文件。数目仅反映测试当时本机，不是功能固定数目。

Test-BackgroundManager.ps1：生产适配层使用模拟任务/Appx 命令；启动文件在新建临时测试目录里真实移动/恢复。验证任务启停、异常回滚、定义变化拒绝、文件哈希、同名冲突、卸载/重新注册流程、清单缺失拒绝、未知 ID/类型/路径拒绝。

Test-StartupScopes.ps1：六类注册表路径使用模拟注册表，不写实际 HKLM/HKCU 启动键；验证原 ExpandString 类型、中文内容、整批回滚和冲突拒绝。

构建及 9 个 Node 回归测试通过。便携包接口验证通过：三类后台目录读取、无确认写入拒绝、原网络/扫描/运行状态读取、已退役接口仍返回 404。浏览器开发预览验证 42 项任务的第二页、搜索后重置分页、启动文件夹/商店应用切换、卸载数据丢失提示与取消。预览使用示例数据，没有确认卸载。

本轮未实测卸载任何用户应用，也没有关闭真实任务。不能将模拟写入测试当成所有硬件、账户、系统版本的真实操作认证。

## 尚未等价的范围

普通 Win32 软件卸载、清理细分、完整服务自定义及修复库、MPO/FSO/HAGS/计时器/存储高级参数、安全产品与漏洞缓解开关仍未全部实现。已退役的游戏优先级和按键库不重新加入。此前记录里“应用只读”“系统级启动项只读”“仅4个预设任务”的限制已被本轮扩展替代，不应再当作当前能力。
