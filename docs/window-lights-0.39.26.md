# 0.39.26 — 开灯 / 关灯

- 偶发启动/退出的状态提示，使用 animate 与 emil-design-eng 指导：只动画 opacity/transform，不缩放文字、不循环闪烁、不逐帧改布局。
- 开启：280ms 顶部蓝色光带、柔光与界面淡入；退出：220ms 收光变暗；托盘隐藏：160ms 简化淡出。使用 cubic-bezier(0.23,1,0.32,1)。
- 跟随现有「外观 → 立体动效」；关闭动效、游戏运行或界面键盘操作后跳过。系统减少动态效果时只保留 160ms 淡化。
- 光效在独立非交互 top-layer 中，不改变内容布局或抢焦点；退出末帧保持到原生隐藏/销毁，避免关灯后闪回亮屏。
- 主进程仅接受当前主窗口主 frame 的 readiness/完成回执；匹配唯一请求 ID。动画无权限决定保存配置、隐藏或退出。
- 650ms 超时兜底；renderer 丢失、未准备、窗口隐藏/最小化时不阻塞退出。托盘淡出期间重新打开取消隐藏，真正退出不可被装饰动画取消。
- 退出动画与原有报告收尾/后台清理并行；关闭确认与记住选择维持原行为。

## 验证

- 262 项 Node 回归测试通过，含错误 sender/旧回执、超时、renderer 失联、反向展开、退出抢占、延迟隐藏和退出等待。
- 真实 Electron + 生产 preload IPC 隔离测试通过：石墨/银白、动画开始与完成、焦点保留、关闭末帧、托盘反向、动效关闭/游戏/键盘跳过、减少动态淡化。
