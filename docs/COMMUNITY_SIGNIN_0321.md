# 0.32.1 签到登录与公共提醒

## 调整

- 左侧菜单下方固定显示今日签到完成数、待确认数、需登录数。位于导航滚动区外，切换菜单或滚动内容不隐藏；窄屏使用独立提醒入口。点击进入社区签到。
- 首页、公共提醒和签到页共享同一份本地状态订阅，不额外轮询官方接口。
- 备注选填，第一行显示备注，下一行显示账号；没有备注时直接显示账号。不再使用“默认账号”。旧版未记录真实账号名称，需要重新完成官方登录后更新。
- 重新登录只重置该本地档案的旧会话，打开官方登录页。连接中、超时、加载失败、空白返回和登录确认均有状态反馈，失败页提供重新加载入口。
- 登录过期不撤销本机已经确认的今日签到回执。保留之前查询到的累计天数；这些数值不用于推断今日是否签到。

## 登录边界

官方登录窗口仍隔离于主界面，启用 sandbox 与 contextIsolation，禁用 nodeIntegration。新增的单向 preload 只观察官方主登录页中明确的 username 文本框，不读取密码、蜗牛盾口令、密保卡、验证码或提交请求体，也不向网页暴露本地 API。主进程校验发送窗口、主 frame 和官方来源；只有提交后官方活动接口确认登录，才采用该账号名称。

登录会话依然分别加密保存在本机，不延长官方过期时间。二维码等没有经过账号文本提交的分支不猜测身份；显示“尚未识别”。用户在官方窗口手动完成二次验证。没有尝试规避登录验证或证书检查。

## 验证

- 61 项 Node 回归测试通过，TypeScript 与生产构建通过。
- 隔离 Electron 环境中官方登录页面成功加载，读取 27 个分区、207 个服务器；加密存储可用。真实签到请求为 0。
- 测试覆盖登录名称来源校验、先提交再确认登录、可选备注、登录过期保留今日回执、空白反馈与公共订阅。
- 隔离示例页检查备注上下层级、清空备注后显示账号、银白及深色主题。真实应用预览检查网络页滚动后固定提醒与点击进入签到管理。
- 实际用户重新登录、蜗牛盾及密保卡验证分支仍需用户完成。匿名页面加载成功不等于已验证用户的登录与签到。

## 使用

退出旧版，打开 `release/0.32.1-signin-relogin/SynapseX-Game-Optimizer-0.32.1.exe`。点击左下角今日签到，选择账号并重新登录。官方窗口完成验证后，关闭窗口并点击账号的刷新按钮，更新账号显示及区服累计天数。

页面证据保存在 `design-evidence/signin-0321/`，示例账号仅存在测试页面，不进入生产包。
