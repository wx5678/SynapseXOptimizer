# 0.39.25 — 工具栏与重新检测反馈

## 界面

- 公共头部合并帮助、更新和外观为轻量工具组；账号独立显示头像、身份徽标和设备/到期信息。
- 服务状态移至同一行，不再在首页标题右侧单独占行。
- 复用现有石墨/银白主题变量；长用户名截断并保留完整提示，键盘焦点可见。
- emil-design-eng 指导此次层级、对齐与轻量按压反馈；不引入额外进场动画。

## 九阴重新检测

原按钮已调用资源读取，但无忙碌/完成反馈；相同结果不产生可见变化。现在显示检测中和带时间的结果，防止连续重复请求，直接提示读取失败、不兼容及缺少原版备份。检测仅读取，不会修改文件或覆盖用户待应用数值。当前文件值与应用后的目标值分别标注。

未调整资源白名单、写入流程、管理员权限或 VIP 到期规则。不会从修改过的资源伪造原版备份。

## 验证

- 257 项 Node 回归测试通过。
- 隔离 Electron 实际组件测试：深浅主题、1360/980 宽度、管理员/VIP/免费/未登录、长用户名、帮助/更新/账号/外观入口。
- 检测组件：读取中禁用、相同结果明确反馈、变化值更新、保留待应用输入、缺少备份提示、失败重试、不兼容提示；零写入。
- TypeScript 与生产构建通过；Vite 仍提示既有大包体积警告。
