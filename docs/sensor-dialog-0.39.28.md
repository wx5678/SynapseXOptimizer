# CPU 温度驱动确认弹窗 · 0.39.28

- 用软件内的主题 dialog 替换 Windows 消息框。复用关闭窗口弹窗的圆角、配色、按钮、遮罩及字体层级，支持深浅主题。
- 区分组件卡片、哈希/签名检查说明、内核服务/管理员授权/可能重启提示；默认聚焦“暂不安装”。
- Esc、右上角 X 和取消均不安装。主进程生成独立请求 ID，校验主窗口主框架、已显示确认和布尔响应；不保存授权。
- 页面重载、渲染进程退出、未及时显示或软件关闭时取消确认。下载、固定版本哈希、签名和官方交互式安装程序流程不变。
- 使用 emil-design-eng 的一致性、焦点和按钮反馈规范；此处不添加装饰性动画。

验证：269 项 Node 回归通过；真实 Electron preload/IPC + React 弹窗深浅主题、窄窗口、Esc/X/取消/确认/重复点击测试通过，截图已检查。
测试仅验证确认结果，不下载、不启动安装程序、不安装驱动。Windows UAC 和第三方安装程序未定制。
