## 已交付范围

桌面版本 **0.36.0**：软件设置中新增“软件授权”，包括激活、刷新、有效期、离线有效期、解除本机授权；使用既有明暗主题。主进程验证 Ed25519 签名、固定公钥、发行者、受众、设备与到期时间。Windows 安全存储加密本地凭据，刷新令牌不传入页面。日常自动续期间隔为 24 小时，不触发 FPS 采集或系统优化。

Windows 成品：`release/0.36.0-licensing/SynapseX-Game-Optimizer-0.36.0.exe`；SHA-256：`15DE1D2E65C16DBBEB5468B32766BF8F592DB1416E2C431B005EE8DEB848BE05`。

授权后台 **0.2.1**：管理页面、管理员登录/退出/修改密码、签发授权码、备注与功能标识、搜索与分页、设备列表、延期、撤销、解绑、操作日志。签发与管理变更防重复提交；撤销与解绑不会立即抹除仍有效的离线许可，最长 7 天。

这不是完整商城或会员系统。尚未实现终端用户账号登录、订单、支付回调、退款流程或分层付费墙。

## 说明与限制

目前客户端能够验证许可，但没有启用任何付费限制。签名无法保证客户端不被破解，DPAPI 也不防同一 Windows 用户上下文内的其他程序访问；设备标识不是不可伪造的硬件证明。源代码或本地文件被恶意修改仍可能绕过客户端检查。

实现参考：[Electron safeStorage](https://www.electronjs.org/docs/latest/api/safe-storage)、[Flask 安全配置](https://flask.palletsprojects.com/en/stable/web-security/)、[Gunicorn 控制 socket 设置](https://gunicorn.org/reference/settings/)。
