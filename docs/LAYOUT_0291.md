# 0.29.1 布局调整

范围：沿用现有浅色/深色主题，调整导航、通用页头及一键优化工作区，不重做系统执行逻辑。

- 主导航直接进入一键优化；更多工具保留诊断、会话、启动项与修复入口。
- 顶部三档卡片明确显示选中态和本机待应用数量。
- 项目清单改为纵向紧凑列表，提供基础设置、服务与任务、隐私与权限分类，以及搜索、已勾选/已是目标值/不可用筛选。
- 右侧执行汇总显示实际勾选数量、目标状态、不可用与取消项数量。最大档影响提示保留在应用按钮之前。
- 完整功能说明逐项展开；分页后回到清单顶部并转移键盘焦点，不修改勾选。
- 最近批次结果和精确备份恢复入口集中于执行汇总下方。
- 帮助按钮通过 portal 挂载到顶栏；抽屉保持根级遮罩，避免覆盖正常操作按钮。
- 窄窗口自动改为上下排列；汇总在矮屏宽窗口中可滚动，避免展开说明后裁切按钮。

验证：

- TypeScript 与 Vite 构建；34 项 Node 回归测试。
- 内置浏览器：浅色、深色；1366×860 与 960×720；无页面横向溢出。
- 最大档搜索麦克风并取消相应权限项，确认清单从 72 降至 71；只打开并取消确认窗口，没有执行优化。
- 已勾选筛选仍保留其他分类的选择；无结果、清除筛选与分页不清空已选内容。
- 下一页显示第二页，滚动至清单顶部，仍保留本档全部勾选。
- 顶部帮助按钮可打开原帮助抽屉，不与应用按钮重叠。

发行：Windows 10/11 x64 便携包，未数字签名。没有声称所有显卡/CPU/系统版本已实机测试。开发验证不向本机应用系统优化。
