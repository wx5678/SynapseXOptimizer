# 0.39.32 原始电源计划库

入口：左侧「更多工具」→「游戏进程会话」→「原始电源计划库」。系统调整中的「CPU 电源方案」快捷入口也可到达。

## 内容与行为

- 收录 `D:\安装包\电源配置` 前次审计中去重后的 75 份有效原始 `.pow`。别名可搜索，同名不同内容使用短哈希区分。
- Windows 已安装计划、原始计划库、按 CPU 推荐的方案并存。原始库不按 CPU 隐藏、不自动选择、不自动启用。
- 选择后展示插电参数摘要、原文件名和已知风险。导入完整原始计划，不只复制摘要中的参数；电池和设备设置也会变化。
- 显式确认整包影响；禁用空闲、自主控制或限定处理器类型的计划再增加一次风险勾选。前后端均校验。
- 原始库只读固定清单和哈希命名文件。导入前校验 SHA256、管理员权限和当前活动计划；导出当前计划并记录哈希，再以新 GUID 导入、读取参数并激活。失败时恢复原计划、清理失败副本。
- 恢复按备份实际时间选择最新记录，不按名称前缀。原 GUID 被删除时可从已校验导出文件恢复。成功导入的计划在恢复后保留在 Windows 列表中。
- 修复中文备份 JSON 的 UTF-8 读取。
- 1 份格式无效文件、1 份未能解密的独立压缩包不开放导入，界面说明原因。不执行压缩包内程序。

## 验证

- Node 自动测试 278 项通过。
- 75 份计划逐个 SHA256 校验通过。
- 模拟导入/恢复 15 个场景通过：权限、整包/高风险确认、非法编号、清单外编号、文件校验、备份失败、导入失败、参数读取失败、激活失败、激活回读不一致、最新备份排序、原 GUID 丢失后恢复等。
- Electron 离屏 UI 测试通过：75 个选项、搜索无结果、确认门槛、切换计划清除确认、恢复回调、深浅色及窄窗口。截图在 `design-evidence/power-library-0.39.32`。
- 构建通过。Vite 仍有已有的单文件大于 500KB 提示。
- 实际便携包双启动检查通过：资源隔离，退出第二个实例不影响第一个实例；包内 75 份计划均再次通过 SHA256 校验。原 CPU 方案的 7 个模拟事务场景也通过。

未在本机激活这些原始计划；文件校验与可导入性不等于适配所有 CPU，也不代表性能收益已经实测。界面沿用现有主题、即时选择反馈和先预览再确认的交互，不增加列表动画。
