# 0.39.13 — 顶部导航与性能报告

## 改动

- 全部 15 个工作区页面共用顶部容器。面包屑、标题、帮助/账号/外观和页面分类不再随正文滚走；标题统一紧凑尺寸；顶部高度由 ResizeObserver 测量，避免压住一键优化侧栏。系统/实验室切换分类回到正文起点。
- 报告与 FPS 采集解耦，FPS 缺失仍记录 CPU/GPU/内存/网络，FPS 采集异常不会阻止开始会话。
- 至少 15 秒且 3 个有效样本后，每 15 秒按稳定会话 ID 更新同一报告；游戏退出连续 3 次确认（正常约 9 秒）后保存最终汇总。采样接口错误不等同于游戏退出。
- 保存前写入 Electron 用户目录中的 performance-report-outbox；失败显示原因，15 秒间隔重试，下次启动恢复待保存记录。旧报告兼容，不改写游戏/系统配置。
- 关闭自动记录会保存已有合格会话，不再直接丢弃。正常关闭主窗口时先请求报告补存，再关闭本地服务和悬浮窗；握手上限 2 秒，异常时可恢复此前的周期快照。
- 记录状态显示游戏、采样次数、时长、最近保存及失败原因；报告在游戏过程中即可查看。阶段记录与结束报告使用不同标签。
- 报告保存和遥测读取不再受产品配置加载/强制更新写操作门禁影响，其他授权与更新限制不变。

## 验证

- Node 回归：199 项；包含周期保存、无 FPS、FPS 故障、遥测错误、短会话丢弃、重试与重启恢复、自动关闭、退出补存、不可变快照、缓存路径校验和退出超时。
- Windows PowerShell 5.1：Test-PerformanceReports.ps1 验证真实临时文件写入/读取/删除、同 ID 更新、完成状态不被旧重试降级、身份冲突拒绝。测试目录隔离于用户报告。
- TypeScript / Vite 生产构建。
- 浏览器隔离预览：15 个页面标题均在顶部容器；长页面实际滚动后 top=48px；系统 8 类、网络 7 类、实验室 6 类随标题固定。检查石墨与银白外观。
- 浅色报告交互夹具：模拟游戏运行、保存失败、恢复和退出，确认单份报告持续更新、错误可见、趋势曲线可见。

## 边界

未启动/退出用户的真实游戏，未替换正在运行的 0.39.8，也未部署云端版本配置或安装温度驱动。真实游戏长时间会话需在新包中复验。
强杀进程/断电不保证保存最后 15 秒内的数据；正常关闭尽力补存，已有周期快照不会因整场仍未结束而丢失。旧版已丢失、从未落盘的会话无法补回。
