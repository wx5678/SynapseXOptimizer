# VIP 功能权限 · 2026-09-15

## 版本与规则

客户端 0.38.0，后台服务 0.3.1；公网入口保持 https://39.96.195.192/admin/ 。

- `quick.maximum`：一键优化的最大档。
- `system.expert`：系统调整的高级参数。
- `network.tcp`：TCP / QoS 设置。
- `network.nic`：网卡高级设置，包括预设和逐项编辑。
- `lab.all`：实验室功能执行。
- `signin.three`：签到账号上限从免费 1 个提高为 3 个。
- 授权标识 `vip` 包含上述全部项目。`test.pilot` 不含 VIP 权益。

后台给软件账号开通授权，功能标识默认填 `vip`；也可用逗号分隔的单项标识授予部分权限。用户在客户端同步后生效。现有已发授权不自动升级为 VIP。当前没有接入价格或收款。

“最佳”方案与高级参数有重复：免费用户仍能运行最佳方案，但其中的高级参数行会标为不可用并自动跳过，防止一批操作中途才遇到权限拒绝。最大方案的选择、开始执行和逐项执行前均检查权限。

## 执行与恢复

主进程根据已验签、未过期且归属正确的账号/旧授权凭证判断功能权限，不信任页面布尔值。受保护的本地 HTTP 路由需要主进程转发的独立运行期凭据；该凭据不放入页面 URL，也不下发给渲染器。GET/POST 请求方式切换不会放行受保护的写入路由。

未授权仍可读取状态、恢复记录并恢复备份；停止会话、调度实验、延迟测试和诊断不受限制。持久实验的注册表和 GPU 恢复记录仍能读取。离线凭证的撤销延迟保持原有规则（最长 7 天，且不超过授权到期时间）。

此限制从新版客户端开始执行，不会给已经分发的旧 EXE 自动补上限制。纯本地代码无法保证不可破解；运行期能力凭据是执行入口隔离，不是对本机管理员的强防护。

## 签到额度

免费 1 个，VIP 3 个。添加账号和打开登录窗口在主进程检查；批量与自动签到逐个检查当前额度，降级时不会继续处理超额账号。

既有超额账号不会删除，依照本地列表顺序，前 1/3 个可用；用户可以移除不需要的账号释放位置。关闭自动签到、查看原记录、退出或移除本地账号不受 VIP 限制。当前账号有效时不借用另一份旧授权的权益。

## 网卡逐项编辑修复

旧页面仅列出属性，只实现少数节能预设，因此很多行没有编辑入口。新编辑器使用驱动返回的 ValidRegistryValues / ValidDisplayValues，数值型使用驱动提供的最小值、最大值和步长；驱动不提供这些元数据时明确保持只读，不猜值。

后端校验唯一网卡、唯一属性、原值未变、合法值与步长；先保存带网卡 GUID 的备份，再用 NoRestart 写入并回读。失败保留备份并报错，恢复时检查网卡归属。不会为了测试而重启真实网卡。

实现依据：[Microsoft Get-NetAdapterAdvancedProperty 文档](https://learn.microsoft.com/en-us/powershell/module/netadapter/get-netadapteradvancedproperty?view=windowsserver2025-ps)。本机只读已确认枚举属性与数值范围均能返回；本次未修改用户真实网卡配置。
