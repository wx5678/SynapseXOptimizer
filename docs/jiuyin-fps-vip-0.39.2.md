# 九阴帧率上限 · 0.39.2

入口：游戏配置 → 九阴帧率上限。VIP 才能应用；查询、导入原版备份和恢复始终免费。

## 首版范围

- 提供已实测的 300 → 360 FPS 界面上限；不是实际帧率保证。
- 只接受已验证的 64 位游戏资源与模块版本。更新、其他工具改动、独立设置 XML 冲突时拒绝应用。
- 只改 `res/skin.package` 内一个已识别的压缩 XML 块；保持资源总长度与块边界不变，不改 DLL，不注入进程。
- 正式功能要求退出游戏。即使之前的手工实验可以在运行中替换，产品仍会在准备、提交和原生替换前检查进程。
- 999 不作为发布档位：内部滑条值 333 超出已发现的单字节持久化范围，重新登录可能回落或产生配置异常。当前资源中的 999 测试版仅被识别为迁移/恢复状态。
- 游戏更新或完整性检查可能覆盖/拒绝此资源修改；出现启动或设置异常应恢复原版。

## 会员到期

主进程每次应用前检查现有签名授权，并在提交前再次校验。原有 `vip` 授权包含新功能 `jiuyin.fps`，不需要重新签发功能清单。

已写入游戏资源的效果不会因会员到期自动撤销。用户不运行本软件、离线或保留修改后的副本时，服务端无法可靠收回本地修改。不得将此功能宣传为“到期自动失效”。软件不偷偷修改游戏来强制恢复。

## 使用与恢复

1. 在游戏配置中选择九阴安装根目录。
2. 游戏内将上限调回不超过 300，正常退出，点击“重新检测”。
3. VIP 点击“备份并应用 360”，阅读并确认提示。
4. 启动游戏，重新打开视频设置，将帧率滑条拉至最右。
5. 恢复前再次将游戏设置调回不超过 300 并退出，然后点击“恢复原版 · 免费”。恢复资源不会直接修改账号保存的滑条值。

首轮原版备份保存于 Electron userData 下 `jiuyin-fps-backups/<安装目录哈希>/original.package`，界面显示实际路径。按完整 SHA-256 校验，已有备份不覆盖。原子替换留下的前一个资源也归档保留。若归档失败，保留同目录 `.previous` 文件并明确提示。

以前手工实验留下的 360/999 资源没有软件管理的备份时，必须通过文件选择器导入该版本原版备份。不能拿另一个客户端版本的资源恢复，也不能把游戏更新回滚到旧版本。缺失原版时使用官方修复功能。
