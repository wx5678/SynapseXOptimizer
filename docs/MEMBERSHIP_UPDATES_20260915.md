# 账号、会员与版本发布（0.39.0 / 服务端 0.4.0）

## 已实现

- 全局右上角“登录 / 注册”；登录后显示软件账号、免费 / VIP 及授权到期日期。
- 未登录访问 VIP 区域或执行 VIP 功能时打开注册入口；免费查看、停止与恢复备份仍保留。
- 软件账号凭据使用系统加密存储，不保存密码。会话为 180 天，在线同步续期；服务端停用、解绑、用户退出或凭据损坏会要求重新登录。
- 免费账号和会员账号都绑定一台设备。升级时保留已有授权设备；退出账号不会解除绑定。后台用户列表“换绑设备”注销所有会话并清空绑定。旧离线授权最多仍可持续 7 天，不能承诺即时撤回离线设备。
- 会员配置：月费 990 分、年费 9900 分，联系微信 `Tens__`，使用用户提供的原始 PNG。仅人工联系开通，没有支付或自动到账。
- 管理设置增加会员与客户端更新配置，可替换二维码、修改价格，支持修订号冲突检测。
- 公共配置由现有 Ed25519 签名密钥签名，客户端固定公钥校验；配置和下载地址不能由渲染层任意指定。
- 更新模式可选 / 强制；只有大于客户端版本的已发布版本才提示。已获知的强制更新在断网或重启后仍阻止进入。未知更新、首次网络失败无法凭空确认有强制版本；签名配置可缓存，过期配置不得用于启动下载。
- 码云 HTTPS 直链下载，校验重定向域名、准确字节数、SHA-256 和 EXE 文件头。进度按真实数据更新。退出软件时终止下载、清理本次未完成临时文件。
- 当前发行物为便携 EXE：下载校验完成后点击“打开下载文件夹”，退出旧版再运行新版。暂未实现安装器自动替换或断点续传。
- 左侧默认图标，鼠标悬停展开文字；不再生成悬停子菜单。键盘操作与减少动画兼容，展开不推挤正文。

## 发布流程

1. 后台“管理设置 → 会员与客户端更新 → 读取 / 刷新配置”。
2. 上传安装包到自己的码云仓库 / 发布页，取得能够匿名下载的 HTTPS 直链，不是仓库网页。尚未收到用户仓库地址，因此未上传代码和安装包。
3. 填版本号、下载直链、SHA-256、文件字节数和说明。价格以元输入、服务器以分存储。
4. 先以“可选更新”发布，在一台旧客户端验证真实下载和新版启动，再改为“强制更新”。没有安装包地址时必须保持“对外发布”关闭。
5. 如果发布配置错误，关闭发布或改为可选。用户可在更新弹窗“刷新版本配置”解除已经撤回的强制更新。

Gitee 直链当前仅接受 `gitee.com` 及其子域名；如真实下载必须跳转其他官方 CDN，需核实具体域名后加入白名单，不能使用任意跳转。代码仓库不应包含服务器数据库、签名私钥、管理员凭据、用户登录缓存或本机日志。

## 部署状态

本轮本地实现与自动化测试已完成；0.4.0 服务端上线尚待用户确认延长登录有效期并公开会员联系信息。线上尚未启用版本发布。不要在上线前声称新后台配置已经可用。

部署包需要包含 `product.py`、`test_product.py`、`admin-web/product.js`、`public-assets/wechat.png`。安装脚本会先执行测试并备份数据库。Nginx 仅 `/admin/api/product` 的正文限制调为 384 KB，其他接口保持 4 KB；数据库与 8787 端口仍只在本机。
